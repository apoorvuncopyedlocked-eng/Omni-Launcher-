# 🔮 Omni Launcher

### A beautiful, aesthetic Minecraft: Java Edition launcher for Android

## ✨ Features

- 🎮 Play Minecraft: Java Edition on Android
- 🌌 Beautiful dark purple aesthetic UI
- 📱 Bottom navigation with Home, Instances, Mods, Servers and Settings tabs
- 🧩 Forge and Fabric mod support
- 🗂️ Instance management
- 🌐 Server browser
- ⚡ Optimized performance
- 🎨 Clean Material Design 3 interface

## 🛠️ Building from Source

```bash
# Clone the repository
git clone --recursive https://github.com/YOUR_USERNAME/Omni-Launcher.git

# Build debug APK
./gradlew :app_pojavlauncher:assembleDebug
```
